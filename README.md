# Notes App

Простое приложение заметок на Flutter.

## Возможности
- ввод текста;
- сохранение заметки;
- отображение заметок в списке;
- редактирование заметки;
- удаление заметки.

## Запуск
1. Открыть проект в Android Studio или VS Code.
2. Выполнить `flutter pub get`.
3. Запустить `flutter run`.

Основной код находится в `lib/main.dart`.
